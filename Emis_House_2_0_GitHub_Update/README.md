# Emi's House 2.0

Upload the contents of this folder to the root of your existing `emis-house` GitHub repository.

This build keeps the existing localStorage key for compatibility with your current planner data.

Highlights:
- refined iOS-style bottom navigation with SVG icons
- Quick Add bottom sheet
- global search
- Today agenda/timeline
- Month / Week / Agenda calendar modes
- cleaner design system and mobile spacing
- existing tasks, budget, birthdays, anniversaries, co-parenting, backup/import preserved
- PWA/offline cache updated

Before a major update, export a backup from Settings.
